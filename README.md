# Word Guess – 5-letter word game (v.2026.1.0)

Multilingual (Turkish, English, Spanish, German) five-letter word game by Caglar Orhan.
Glass UI, light/dark/system theme, Standard and Timer modes with separate scores, installable PWA that works offline.

- `index.html` – the whole game (self-contained, no outside requests)
- `manifest.webmanifest`, `sw.js`, `icons/` – PWA files
- `docs/removed-words.txt` – words removed from the dictionaries

The original multi-file version is kept in the `classic` branch.
